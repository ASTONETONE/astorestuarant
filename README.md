# AstoRestuarant
A modern, scalable and responsive website build with HTML5, CSS3, and Javascript

## FEATURES
- Responsive website with mobile toggle bar navigation
- Dark blue theme background with eye strain reduced
- Sticky Navigation bar hence scrolling doesn't diplace it
- Responsive text from desktop view all the way to mobile view
- Active buttons for sending email
- Alert technology once you click the button

## TECHNOLOGIE USED
- HTML5
- CSS33
- JAVASCRIPT

## GETTING STARTED
- Clone or download this respiratory
- Open the folder inside the VS Code
- Open `index.html` using liveserver
